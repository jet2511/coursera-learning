## 1. Ba trụ cột cốt lõi của Front-End Web
Website được ví như một ngôi nhà:
- **HTML (Hypertext Markup Language):** Khung kết cấu chịu lực của ngôi nhà (văn bản, nút bấm, hình ảnh, video, liên kết, phân đoạn trang). Đảm bảo cấu trúc hiển thị đồng nhất trên các trình duyệt.
- **CSS (Cascading Style Sheets):** Thiết kế nội thất/thẩm mỹ (font chữ, màu sắc, layout, spacing). Giúp giao diện đồng bộ, nhất quán và hỗ trợ tương thích đa trình duyệt (cross-browser compatibility) và thiết bị (PC, mobile, tablet).
- **JavaScript:** Hệ thống điện nước, vận hành (tương tác & hành vi). Là ngôn ngữ lập trình hướng đối tượng dùng để thêm tính năng động (ví dụ: HTML tạo nút login, CSS làm đẹp nút, JS xử lý logic khi bấm nút login).

---

## 2. Công cụ mở rộng CSS (CSS Preprocessors)
- **SASS (Syntactically Awesome Style Sheets):** Bản mở rộng của CSS, hỗ trợ biến (variables), lồng quy tắc (nested rules), inline imports. Giúp viết code CSS gọn gàng, nhanh và dễ tổ chức hơn.
- **LESS (Leaner Style Sheets):** Bổ sung hàm và kiểu dáng mở rộng cho CSS, tương thích ngược. Sử dụng `LESS.js` để biên dịch sang CSS thuần.

---

## 3. Thiết kế hiển thị: Adaptive vs Responsive
- **Adaptive Design:** Tạo ra các phiên bản layout cố định khác nhau cho từng kích thước màn hình cụ thể (ví dụ: giao diện desktop hiển thị nhiều dữ liệu hơn giao diện mobile).
- **Responsive Design:** Giao diện tự động co giãn, dàn trang linh hoạt theo kích thước của thiết bị đang truy cập, giữ nguyên đầy đủ tính năng.

## 4. Các JavaScript Frameworks & Libraries phổ biến
| Framework / Library | Người duy trì | Đặc điểm & Phạm vi |
| :--- | :--- | :--- |
| **Angular** | Google | Framework mã nguồn mở toàn diện (Full-featured suite), tích hợp sẵn routing, form validation; render HTML nhanh và hiệu quả. |
| **React.js** | Meta (Facebook) | Library chuyên về component UI. Chỉ tập trung xây dựng và render component; các tính năng khác (như routing) cần tích hợp thêm thư viện bên thứ 3. |
| **Vue.js** | Cộng đồng | Tập trung mạnh vào view layer (UI, buttons, visual components). Rất linh hoạt và dễ mở rộng, có thể dùng như một library hoặc toàn bộ framework. |

---

## 5. Trách nhiệm chính của Front-End Developer
- Đảm bảo website hoạt động mượt mà trên đa trình duyệt (cross-browser), đa hệ điều hành (cross-OS) và đa thiết bị.
- Liên tục cập nhật các công nghệ, thư viện, chuẩn giao diện người dùng mới.
