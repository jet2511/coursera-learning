## 1. Cơ chế hoạt động cơ bản giữa Client & Server
- **Client (Trình duyệt):** Người dùng nhập URL (ví dụ: `www.ibm.com`) vào address bar của trình duyệt (Chrome, Safari, Edge, Firefox). Trình duyệt gửi request đến server để yêu cầu tài nguyên.
- **Server:** Xử lý và phản hồi (response) trả về dữ liệu cần thiết cho trình duyệt hiển thị:
  - **HTML:** Định nghĩa cấu trúc khung của trang web.
  - **CSS:** Định hình giao diện, màu sắc, bố cục (style & flair).
  - **JavaScript:** Thêm tính năng tương tác (interactivity) và nội dung động.

---

## 2. Phân loại nội dung website & Cloud Apps
- **Static Content:** Dữ liệu lưu sẵn trên server, không thay đổi theo từng request.
- **Dynamic Content:** Nội dung được sinh ra theo thời gian thực mỗi khi client gửi yêu cầu, thường tích hợp từ cơ sở dữ liệu hoặc hệ thống backend khác.
- **Cloud Applications:** 
  - Tương tự website truyền thống về mô hình Client - Server.
  - Vận hành trực tiếp trên nền tảng hạ tầng đám mây (Cloud storage, Cloud processing, Managed Cloud services), đem lại khả năng **mở rộng cao (scalable)** và **tính chịu lỗi/phục hồi cao (resilient)**.

---

## 3. Các phân vùng trong phát triển phần mềm
| Vùng | Trách nhiệm chính | Công nghệ / Đặc điểm |
| :--- | :--- | :--- |
| **Front-End (Client-Side)** | Xử lý những gì hiển thị trực tiếp cho người dùng thấy và tương tác. | HTML, CSS, JavaScript và các frameworks/libraries liên quan. |
| **Back-End (Server-Side)** | Xử lý logic nghiệp vụ, tính toán, xác thực (auth/security) và lưu trữ dữ liệu trên server. | Ngôn ngữ backend (Java, Python, Node.js,...), Relational / NoSQL Databases. |
| **Full-Stack** | Bao quát toàn diện cả hai môi trường front-end và back-end. | Kiến thức end-to-end từ client, API, database đến server. |

---

## 4. Công cụ lập trình (Code Editors & IDEs)
- **Code Editor:** Công cụ soạn thảo mã nguồn cơ bản (như Sublime Text, Atom, Vim).
- **IDE (Integrated Development Environment):** Tích hợp môi trường hoàn chỉnh phục vụ viết mã, build, compile, debug và quản lý source control (Git/GitHub), hỗ trợ extensions/themes:
  - Ví dụ: VS Code, Visual Studio, Eclipse, NetBeans, IntelliJ IDEA.
