# Data Migration Overview

## 1. Core Concept & Objectives
- **Data Migration**: Chuyển giao dữ liệu từ hệ thống này sang hệ thống khác hiệu quả và an toàn.
- **Key Objectives**:
  - **Data Integrity**: Bảo toàn tính trọn vẹn, không thất thoát/sai lệch.
  - **Operational Continuity**: Giảm thiểu gián đoạn (*zero/minimal downtime*).
  - **Target Capabilities**: Khai thác tối đa hiệu năng, tính năng mới.

1. **Planning & Assessment**: Phân tích source & target, data types, dependencies, schema mapping, rủi ro tương thích.
2. **Data Extraction**: Rút trích dữ liệu bằng *export tools* hoặc *custom scripts*.
3. **Data Transformation**: Chuẩn hóa kiểu dữ liệu, reformat records, tái cấu trúc bảng khớp schema đích.
4. **Data Loading**: Nạp vào target database kèm giám sát chặt (*monitoring*).
5. **Validation & Testing**: Xác thực toàn vẹn (*integrity*), hiệu năng (*performance*), tương thích (*compatibility*).

## 3. Common Migration Types

### OLTP to OLAP (Data Warehouse & BI)
- **Source (OLTP)**: Normalized, giao dịch real-time (sales, inventory), không tối ưu cho truy vấn phức tạp.
- **Process**: Denormalize, aggregate, cấu trúc theo **Star Schema** hoặc **Snowflake Schema**.
- **Target (OLAP)**: Hỗ trợ multidimensional analysis mà không ảnh hưởng hiệu năng OLTP.
- **Refresh**: Cập nhật định kỳ qua *batch* hoặc *real-time*.

### On-Premises to Cloud (AWS, Azure, GCP)
- **Lợi ích**: Tăng khả năng mở rộng (*scalability*), truy cập (*accessibility*), khôi phục thảm họa (*disaster recovery*).
- **Quy trình**: Assessment $\rightarrow$ Preparation (clean, compress, encrypt) $\rightarrow$ Transfer.
- **Phương thức chuyển (Transfer Methods)**:
  - **Direct Upload**: Đẩy trực tiếp qua mạng.
  - **Hybrid Migration**: Kết hợp song song local và cloud.
  - **Physical Data Transfer**: Thiết bị phần cứng chuyên dụng cho dữ liệu lớn (AWS Snowball, Azure Data Box).

---

## 4. Key Drivers (Lý do di chuyển)
- **Legacy System Upgrade**: Thay thế hệ thống cũ, hiện đại hóa công nghệ.
- **DBMS Upgrades**: Lên phiên bản CSDL mới, đảm bảo tính liên tục nghiệp vụ.
- **Mergers & Acquisitions (M&A)**: Hợp nhất các nguồn dữ liệu rời rạc thành một hệ thống chung.
- **Cloud Adoption**: Tối ưu chi phí (*cost efficiency*), linh hoạt (*flexibility*), cải thiện backup & disaster recovery.

---

## 5. Best Practices
- **Careful Planning**: Tránh data loss, downtime ngoài dự kiến.
- **Security & Integrity**: Mã hóa (*encryption*), kiểm soát truy cập và kiểm tra toàn vẹn.
- **Compatibility Testing**: Kiểm thử môi trường đích trước khi go-live.
