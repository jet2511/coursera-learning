# Course Introduction & Overview

## 1. Mục tiêu và Đối tượng của Khóa học
- **Mục tiêu chính:** Cung cấp kiến thức nền tảng và kỹ năng thực hành về:
  - Các kỹ thuật tích hợp dữ liệu (**Data Integration**).
  - Lựa chọn giải pháp lưu trữ dữ liệu phù hợp (**Data Storage**).
  - Xây dựng quy trình di chuyển dữ liệu hiệu quả (**Data Migration**).
  - Đảm bảo chất lượng dữ liệu (**Data Quality**), tính nhất quán (**Consistency**) và toàn vẹn (**Integrity**) xuyên suốt hệ thống.
- **Đối tượng phù hợp:**
  - Data Managers, Tech Leads, Engineers muốn nâng cao kỹ năng quản lý dữ liệu.
  - Người làm phân tích dữ liệu, quản lý dự án, người chuyển ngành quan tâm đến lưu trữ đám mây, Data Governance và Compliance.

---

## 2. Các kỹ năng & Nội dung trọng tâm
- **Data Integration:**
  - Triển khai các mô hình tích hợp: B2B Integration, Application Integration, Database Integration.
  - Công nghệ & kiến trúc: Data Warehouse, Data Lake, Streaming Data, ETL/ELT pipelines, Data Propagation.
- **Data Storage:**
  - Đánh giá và lựa chọn giải pháp lưu trữ Cloud phù hợp cho từng loại ứng dụng (Azure/Cloud storage).
  - Kỹ thuật sao lưu (Backup) đảm bảo tính toàn vẹn (Integrity) và lưu giữ (Retention).
- **Data Migration:**
  - Xây dựng kế hoạch di chuyển dữ liệu nhằm giảm thiểu tối đa downtime/disruption khi chuyển đổi hệ thống.
  - Xử lý các rủi ro, lỗi phổ biến khi di chuyển dữ liệu.

---

## 3. Thực hành & Dự án Capstone
- **Labs thực hành:**
  - Sử dụng Power BI cho quy trình ETL (Extract - Transform - Load).
  - Tiêu thụ REST APIs trong Power BI.
  - Làm việc với Azure Data Storage.
- **Capstone Project (Module 3):**
  - Tích hợp và di chuyển dữ liệu tài chính qua các hệ thống legacy cho một công ty đầu tư toàn cầu.

---

## 4. Lộ trình Module 1: Data Integration
1. **Data Integration Patterns:** Giới thiệu patterns, Point-to-Point, ETL Pattern, mô phỏng ETL Power BI.
2. **Connectors & Integration Mechanism:** Data Connectors, Database Connectors, REST APIs trong Power BI.
3. **Data Integration Deep Dive:** Security, Technical Architecture, Tools Overview, Operations Management.
4. **Assessment:** Practice quizzes & Graded Quiz Module 1.
