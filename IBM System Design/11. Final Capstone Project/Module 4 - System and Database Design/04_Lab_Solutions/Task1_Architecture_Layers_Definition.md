# Task 1: Identify Key Architecture Layers (Layer Definition Table)

Bảng định nghĩa 8 tầng kiến trúc công nghệ cho nền tảng ngân hàng số Retail Bank.

| Tầng kiến trúc (Layer) | Chức năng nghiệp vụ & Kỹ thuật (Function) | Các công nghệ ứng viên (Candidate Technologies) | Lựa chọn khuyến nghị (Recommended Choice) | Lý do biện minh (Justification) |
| :--- | :--- | :--- | :--- | :--- |
| **1. Front-End** | Giao diện cổng thông tin khách hàng (Web Portal, Mobile Banking), quy trình mở tài khoản eKYC, dashboard tài chính. | React, Angular, Vue.js, Flutter | **React (Web) + React Native (Mobile)** | Tiêu chuẩn công nghiệp hàng đầu cho ngân hàng số; khả năng tái sử dụng component cao, Virtual DOM tốc độ cao, hỗ trợ kiến trúc Micro-frontends hoàn hảo và chia sẻ code giữa Web và Mobile. |
| **2. Back-End** | Xử lý nghiệp vụ lõi (Customer Services, Payments, Loan workflows), API Gateway, quản lý giao dịch phân tán. | Java Spring Boot, .NET Core, Node.js (NestJS), Go | **Java Spring Boot** | Tiêu chuẩn vàng của ngành tài chính - ngân hàng; hệ sinh thái trưởng thành, kiểm soát đa luồng (multi-threading) vượt trội, bảo mật lớp doanh nghiệp (Spring Security), hỗ trợ trọn vẹn mô hình Microservices và kiến trúc Clean Architecture. |
| **3. Database** | Lưu trữ giao dịch tài chính ACID, thông tin khách hàng, số dư tài khoản và dữ liệu kiểm toán. | Oracle Database, PostgreSQL, MySQL, MongoDB | **Oracle Database (Core Banking) + PostgreSQL (Microservices & Analytics)** | Kiến trúc Polyglot Persistence: Oracle mang lại độ tin cậy tuyệt đối về ACID, bảo mật cấp độ quân sự và tính ổn định lịch sử cho Sổ cái Lõi (Core Ledger). PostgreSQL mã nguồn mở giúp giảm TCO, tối ưu cho các Microservices độc lập và mở rộng linh hoạt. |
| **4. Integration & Middleware** | Tích hợp thời gian thực & xử lý batch với bên thứ 3 (Cổng thanh toán, Trung tâm CIC, Core cũ), hàng đợi tin nhắn. | Apache Kafka, IBM MQ, MuleSoft, RabbitMQ | **Apache Kafka + MuleSoft (hoặc Kong API Gateway)** | Kafka dẫn đầu về truyền phát sự kiện thời gian thực (Event Streaming) với thông lượng hàng triệu msg/sec, lưu vết kiểm toán bất biến (Audit logs). MuleSoft/Kong quản trị vòng đời API toàn diện (API-led connectivity). |
| **5. Analytics & BI** | Báo cáo quản trị (MIS), phân tích rủi ro tín dụng thời gian thực, phát hiện gian lận (Fraud Detection), dashboard kinh doanh. | Microsoft Power BI, Tableau, IBM Cognos | **Microsoft Power BI** | Tối ưu chi phí bản quyền, tích hợp sâu với cơ sở dữ liệu và hệ sinh thái Office 365; hỗ trợ cơ chế quản trị dữ liệu (Data Governance) và bảo vệ dữ liệu nhạy cảm rất chặt chẽ theo chuẩn ngân hàng. |
| **6. DevOps & CI/CD** | Tự động hóa build, test, scan mã nguồn bảo mật (SAST/DAST), đóng gói container và điều phối tự động mở rộng. | GitHub Actions, Jenkins, GitLab CI, Docker, Kubernetes (EKS/OpenShift) | **GitHub Actions + Docker + Kubernetes** | Pipeline Cloud-native khép kín; Kubernetes đảm bảo tính sẵn sàng cao (High Availability), tự phục hồi (Self-healing) và tự động mở rộng (Auto-scaling); GitHub Actions tích hợp liền mạch với kho mã nguồn. |
| **7. Security & IAM** | Xác thực danh tính tập trung, phân quyền dựa trên vai trò (RBAC), bảo vệ đa yếu tố (MFA), tuân thủ PCI-DSS & SOC 2. | Azure AD (Entra ID), Keycloak, Okta, Ping Identity | **Azure AD (Entra ID) + OAuth 2.0 / OIDC** | Giải pháp IAM cấp doanh nghiệp; tích hợp sẵn xác thực thích ứng (Conditional Access), MFA bảo mật cao, quản lý danh tính nhân viên và đối tác, đạt toàn diện các chứng chỉ SOC 2, ISO 27001, PCI-DSS. |
| **8. Cloud & Hosting** | Hạ tầng tính toán, lưu trữ, mạng và bảo mật vật lý/ảo hóa cho toàn bộ hệ thống ngân hàng. | AWS, Microsoft Azure, IBM Cloud, On-Premises Private Cloud | **AWS (hoặc Hybrid Cloud với AWS Outposts)** | Nền tảng đám mây trưởng thành nhất cho ngành tài chính (BFSI); mạng lưới chứng chỉ tuân thủ an toàn rộng nhất, hỗ trợ các dịch vụ quản trị chuyên biệt (Amazon Aurora, EKS, MSK, KMS HSM) đáp ứng yêu cầu khắt khe của ngân hàng trung ương. |
