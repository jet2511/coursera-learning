# Task 1: Identify Security Layers and Components

Bảng định nghĩa các tầng an ninh bảo mật, các thành phần công nghệ nòng cốt và mục đích phòng thủ cho hệ thống ngân hàng số Retail Bank.

---

## 1. Bảng phân tầng an ninh bảo mật (Security Layers & Components Table)

| STT | Tầng bảo mật (Security Layer) | Các thành phần nòng cốt (Key Security Components) | Mục đích phòng thủ & Giá trị kỹ thuật (Security Purpose & Technical Value) |
| :---: | :--- | :--- | :--- |
| **1** | **Network Security Layer**<br>*(Tầng An ninh Mạng)* | - External Firewall (Packet Filtering & Anti-DDoS)<br>- Web Application Firewall (WAF)<br>- Secure Access Service Edge (SASE / Cloud Edge)<br>- VPN Gateway (IPsec / SSL VPN)<br>- Demilitarized Zone (DMZ)<br>- Internal Stateful Inspection Firewall<br>- Micro-segmentation (VPC Subnets & Security Groups) | Ngăn chặn các cuộc tấn công biên giới mạng từ Internet (DDoS, Botnets, quét cổng); kiểm soát lưu lượng Bắc - Nam (North-South traffic) và cô lập lưu lượng Đông - Tây (East-West traffic) giữa các phân vùng mạng. |
| **2** | **Application Security Layer**<br>*(Tầng An ninh Ứng dụng)* | - Secure SDLC Governance<br>- DevSecOps CI/CD Pipeline<br>- SAST (Static Code Analysis - SonarQube)<br>- DAST (Dynamic Testing - OWASP ZAP)<br>- Secret Scanning & SCA (Trivy / Snyk)<br>- Enterprise API Gateway (OAuth2, Rate Limiting)<br>- Runtime Application Self-Protection (RASP) | Ngăn ngừa các lỗ hổng OWASP Top 10 (SQL Injection, XSS, Broken Auth); rà soát mã độc và lộ lọt secret trước khi deploy; API Gateway đóng vai trò chốt chặn kiểm soát truy cập và điều tiết tải ứng dụng. |
| **3** | **Data Security Layer**<br>*(Tầng An ninh Dữ liệu)* | - Data Discovery & Classification Engine<br>- Transparent Data Encryption (TDE - AES-256)<br>- In-Transit Encryption (TLS 1.3 / mTLS)<br>- Hardware Security Module (KMS / CloudHSM)<br>- Tokenization & Dynamic Data Masking<br>- Fine-grained Access Control (RBAC & ABAC)<br>- Sensitive Data Zones (PCI-DSS, eKYC, AML) | Bảo vệ tính bí mật và toàn vẹn của dữ liệu tài chính ở cả trạng thái lưu trữ (At-Rest) và trên đường truyền (In-Transit); token hóa số thẻ thanh toán để tuân thủ PCI-DSS Level 1; phân quyền truy cập nghiêm ngặt. |
| **4** | **Monitoring & Response Layer**<br>*(Tầng Giám sát & Ứng phó)*| - Security Information & Event Management (SIEM)<br>- Security Operations Center (SOC Dashboard 24/7)<br>- Data Loss Prevention (DLP Engine)<br>- Endpoint Detection & Response (EDR / XDR)<br>- Incident Response Workflow Engine<br>(Alerts → Analyst Triage → Containment → Recovery) | Thu thập và tương quan hóa log an ninh thời gian thực từ tất cả các tầng; phát hiện hành vi xâm nhập bất thường hoặc rò rỉ dữ liệu nhạy cảm; kích hoạt quy trình cách ly và ngăn chặn sự cố tự động. |
| **5** | **Identity & Access Management (IAM)**<br>*(Lớp Nhận dạng xuyên suốt)* | - Azure AD / Entra ID (Centralized Identity Provider)<br>- Multi-Factor Authentication (MFA / FIDO2 / Biometrics)<br>- Single Sign-On (SSO via OpenID Connect / SAML)<br>- Privileged Access Management (PAM - CyberArk)<br>- Adaptive Conditional Access Policies | Đảm bảo nguyên lý "Never Trust, Always Verify" của Zero-Trust; xác thực danh tính mạnh mẽ cho khách hàng và nhân viên nội bộ; kiểm soát đặc quyền quản trị viên máy chủ và cơ sở dữ liệu. |
