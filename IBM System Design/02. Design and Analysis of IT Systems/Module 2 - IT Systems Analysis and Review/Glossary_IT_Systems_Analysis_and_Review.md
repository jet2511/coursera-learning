# Glossary: IT Systems Analysis and Review

> **Nguồn:** IBM System Design – Module 2: IT Systems Analysis and Review  
> **Tổng hợp thuật ngữ:** Bảng thuật ngữ tra cứu chuẩn Anh - Việt phục vụ phân tích, thiết kế và đánh giá hệ thống CNTT  
> **Ngày lưu:** 2026-08-14

---

| Thuật ngữ (Term) | Định nghĩa tiếng Anh (Course Definition) | Giải nghĩa tiếng Việt (Vietnamese Context) |
|---|---|---|
| **A/B testing** | A method to compare two interface versions to determine which performs better based on user metrics such as task completion time or click-through rates. | Kiểm thử A/B: Phương pháp so sánh 2 phiên bản giao diện để đo lường hiệu quả (thời gian hoàn thành, CTR). |
| **Accessibility (a11y)** | A method to ensure that a system is usable by people with disabilities by adhering to standards such as WCAG 2.1 (e.g., screen readers). | Khả năng tiếp cận: Đảm bảo người khuyết tật có thể sử dụng hệ thống theo chuẩn WCAG 2.1 (hỗ trợ đọc màn hình). |
| **Activity diagrams** | A tool to model process flows using UML, including activities, decisions, and parallel tasks. | Sơ đồ hoạt động: Công cụ UML mô hình hóa luồng quy trình, điểm rẽ nhánh và các tác vụ song song. |
| **Analytics tracking** | A process to monitor user behavior to identify UI/UX issues, such as drop-off points in a checkout flow. | Giám sát hành vi: Theo dõi hành vi người dùng bằng công cụ phân tích để phát hiện điểm rơi rớt trong quy trình. |
| **API (Application Programming Interface)** | A set of rules enabling software applications to exchange data, used for system integration. | Giao diện lập trình ứng dụng: Tập hợp các giao thức chuẩn cho phép các phần mềm trao đổi dữ liệu và tích hợp. |
| **Architecture documentation** | A record of the components and structure of a system, including modules and dependencies. | Tài liệu kiến trúc: Bản ghi chi tiết về thành phần, cấu trúc module và các mối phụ thuộc của hệ thống. |
| **Availability** | A measure of the percentage of time a system remains operational (e.g., AWS S3 99.99% uptime). | Tính sẵn sàng: Tỷ lệ phần trăm thời gian hệ thống hoạt động ổn định và có thể truy cập được. |
| **Benchmarking** | A method to compare a system's performance or features against standards or competitors. | Đánh giá chuẩn đối sánh: So sánh hiệu năng hoặc tính năng của hệ thống với tiêu chuẩn ngành hoặc đối thủ. |
| **Bottlenecks** | Points where the system performance slows down, such as inefficient database queries. | Điểm nghẽn cổ chai: Điểm làm chậm toàn bộ hệ thống (VD: query DB chưa tối ưu, nghẽn I/O). |
| **Break-even point** | A point where the total benefits of a system equal its total implementation costs. | Điểm hòa vốn: Thời điểm mà tổng lợi ích thu về bằng chính xác tổng chi phí đầu tư triển khai. |
| **Budget overrun** | A condition where the actual costs of a project exceed the original budget estimates. | Đội ngân sách: Tình trạng chi phí thực tế vượt quá mức dự toán ngân sách ban đầu của dự án. |
| **Business Intelligence (BI)** | A tool that analyzes data to support business decisions through dashboards and KPIs. | Trí tuệ doanh nghiệp: Công cụ phân tích dữ liệu lớn, trực quan hóa qua Dashboard/KPIs hỗ trợ ra quyết định. |
| **Business objectives** | A set of strategic goals that guide system selection and implementation decisions. | Mục tiêu kinh doanh: Các mục tiêu chiến lược định hướng cho việc lựa chọn và triển khai giải pháp CNTT. |
| **BPMN (Business Process Model and Notation)** | A diagramming standard used to visualize and optimize workflows. | Chuẩn sơ đồ hóa quy trình kinh doanh: Ký hiệu chuẩn trực quan hóa và tối ưu hóa workflow. |
| **BPR (Business Process Reengineering)** | A strategy to radically redesign processes for improvement, often using IT automation. | Tái cấu trúc quy trình kinh doanh: Chiến lược tái thiết kế triệt để quy trình để tạo đột phá bằng tự động hóa. |
| **Centralized database** | A data repository that consolidates information in one location, such as in ERP systems. | Cơ sở dữ liệu tập trung: Kho lưu trữ hợp nhất dữ liệu toàn doanh nghiệp tại một nơi duy nhất. |
| **Change management** | A strategy to help users adapt to system changes through training and communication. | Quản trị sự thay đổi: Chiến lược đào tạo và truyền thông giúp nhân viên thích ứng với hệ thống mới. |
| **Cloud migration** | A method to move data or applications to cloud platforms. | Di chuyển lên đám mây: Quá trình chuyển dịch dữ liệu, ứng dụng từ On-premises lên hạ tầng Cloud. |
| **Cloud services (IaaS, PaaS, SaaS)** | Scalable, on-demand computing resources provided online. | Dịch vụ đám mây: Cung cấp tài nguyên tính toán theo nhu cầu và có thể mở rộng linh hoạt qua Internet. |
| **Compatibility** | A system's ability to integrate smoothly with existing infrastructure. | Tính tương thích: Khả năng tích hợp mượt mà của hệ thống mới với hạ tầng và phần mềm hiện có. |
| **Compliance** | A requirement to meet specific legal, regulatory, or organizational standards. | Tính tuân thủ: Đáp ứng các quy định pháp lý, tiêu chuẩn an toàn bắt buộc (GDPR, HIPAA, ISO). |
| **Component diagrams** | A diagram showing system modules and their interactions to assess modular design. | Sơ đồ thành phần: Bản vẽ UML thể hiện các module phần mềm và cách chúng tương tác với nhau. |
| **Consulting services** | Professional services providing expert advice on IT solution planning and deployment. | Dịch vụ tư vấn: Dịch vụ cung cấp lời khuyên chuyên gia về lập kế hoạch và triển khai giải pháp IT. |
| **Contact management** | A feature in CRM systems for storing, organizing, and accessing customer information. | Quản lý danh bạ khách hàng: Tính năng CRM lưu trữ, tổ chức và truy xuất thông tin tương tác khách hàng. |
| **Cost-benefit analysis (CBA)** | A tool to compare financial costs and benefits to assess viability. | Phân tích chi phí - lợi ích: Công cụ đánh giá tính khả thi bằng cách so sánh chi phí với lợi ích thu về. |
| **Cost efficiency** | A strategy to minimize expenses while maximizing solution value. | Hiệu quả chi phí: Tối thiểu hóa chi phí phát sinh trong khi tối đa hóa giá trị giải pháp mang lại. |
| **Cost reduction** | A decrease in expenses resulting from improved processes or automation. | Cắt giảm chi phí: Giảm bớt ngân sách vận hành nhờ cải tiến quy trình hoặc tự động hóa. |
| **Customer focus** | A principle that prioritizes delivering customer value in process design. | Lấy khách hàng làm trọng tâm: Nguyên tắc thiết kế quy trình luôn ưu tiên giá trị cho khách hàng. |
| **CRM (Customer Relationship Management)** | A system that manages customer interactions to improve satisfaction and retention. | Hệ thống quản lý quan hệ khách hàng: Nền tảng quản lý bán hàng, marketing và CSKH đa kênh. |
| **Customer satisfaction** | A measure of how well a system meets the expectations and needs of its users. | Mức độ hài lòng của khách hàng: Thước đo đánh giá khả năng đáp ứng kỳ vọng của người dùng. |
| **Data compatibility** | A state where data formats are aligned across systems to allow accurate exchange or migration. | Tương thích dữ liệu: Dữ liệu đồng nhất về định dạng để trao đổi hoặc chuyển đổi không bị lỗi. |
| **Data Flow Diagrams (DFDs)** | A tool to visually map data movement through processes and entities. | Sơ đồ luồng dữ liệu: Công cụ trực quan hóa luồng di chuyển dữ liệu giữa các thực thể và tiến trình. |
| **Data migration** | A process of transferring data from one system or storage environment to another. | Chuyển đổi dữ liệu: Quá trình chuyển dữ liệu từ hệ thống cũ sang môi trường lưu trữ mới. |
| **Data silos** | Isolated data repositories that hinder integration due to incompatibility. | Ốc đảo dữ liệu: Các kho dữ liệu bị cô lập, không thể liên thông với các phòng ban khác. |
| **Decision trees** | A visual tool used to map decision criteria and potential outcomes. | Cây quyết định: Sơ đồ phân nhánh tiêu chí đánh giá và các kết quả/lựa chọn tương ứng. |
| **Deployment diagrams** | A diagram that shows the physical deployment of software and hardware components. | Sơ đồ triển khai: Bản vẽ UML thể hiện vị trí triển khai phần mềm trên các thiết bị phần cứng. |
| **Deployment time** | A measure of the time required to install and configure a new system. | Thời gian triển khai: Thời gian cần thiết để cài đặt, cấu hình và đưa hệ thống vào vận hành. |
| **Downtime** | A period during which a system is unavailable or non-operational. | Thời gian chết (Downtime): Khoảng thời gian hệ thống ngừng hoạt động, không thể truy cập. |
| **Durability** | A measure of how likely stored data remains intact over time. | Độ bền vững dữ liệu: Khả năng dữ liệu lưu trữ không bị mất mát hay hư hại theo thời gian. |
| **Ease of use** | A measure of how intuitive and user-friendly a system's interface is. | Tính dễ sử dụng: Độ trực quan và thân thiện của giao diện đối với người dùng thao tác. |
| **Efficiency gains** | A benefit achieved through process improvements, such as time savings. | Gia tăng hiệu suất: Lợi ích thu được từ cải tiến quy trình (tiết kiệm thời gian, nhân lực). |
| **Electronic Health Record (EHR)** | A system for digitally managing patient data in compliance with regulations. | Bệnh án điện tử: Hệ thống quản lý dữ liệu y tế của bệnh nhân đảm bảo tính bảo mật và pháp lý. |
| **Encryption** | A method to secure data by converting it into an unreadable format. | Mã hóa dữ liệu: Chuyển dữ liệu sang dạng mật mã không thể đọc được nếu không có khóa giải mã. |
| **Enterprise Content Management (ECM)** | A system used to manage digital content such as documents and images. | Quản lý nội dung doanh nghiệp: Hệ thống lưu trữ bảo mật, quản lý tài liệu và tài sản số. |
| **Enterprise Resource Planning (ERP)** | A platform that integrates core business functions such as finance and logistics. | Hệ thống hoạch định nguồn lực doanh nghiệp: Nền tảng hợp nhất tài chính, kho vận, sản xuất, nhân sự. |
| **Entity-Relationship Diagrams (ERDs)** | A diagram used to model data structures with entities, attributes, and relationships. | Sơ đồ quan hệ thực thể: Mô hình hóa cấu trúc cơ sở dữ liệu gồm thực thể, thuộc tính và khóa liên kết. |
| **Evaluation criteria** | Factors used to assess IT solutions, such as cost, usability, or scalability. | Tiêu chí đánh giá: Các yếu tố làm thước đo chọn giải pháp IT (chi phí, tính dễ dùng, khả năng mở rộng). |
| **Feasibility analysis** | An assessment of whether a proposed solution is technically and operationally practical. | Phân tích tính khả thi: Đánh giá xem giải pháp có khả thi về mặt kỹ thuật, chi phí và vận hành không. |
| **Financial risks** | Uncertainty related to costs or funding associated with system implementation. | Rủi ro tài chính: Bất ổn liên quan đến chi phí đội vốn, vượt ngân sách hoặc thiếu hụt dòng tiền. |
| **Functionality** | A set of features or capabilities provided by a system to perform tasks. | Tính năng / Chức năng: Tập hợp các khả năng kỹ thuật hệ thống cung cấp để giải quyết bài toán. |
| **Future-readiness** | A system's ability to scale or adapt to meet anticipated future demands. | Sẵn sàng cho tương lai: Năng lực thích ứng và mở rộng của hệ thống trước nhu cầu phát triển tương lai. |
| **Gap analysis** | A method to identify differences between current and required system capabilities. | Phân tích khoảng trống: Xác định độ chênh lệch giữa năng lực hiện tại (*As-Is*) và mục tiêu (*To-Be*). |
| **GDPR** | General Data Protection Regulation (EU data privacy regulation). | Quy định bảo vệ dữ liệu chung của Châu Âu về quyền riêng tư và xử lý dữ liệu cá nhân. |
| **Hardware upgrades** | Replacement or addition of physical components to meet new system requirements. | Nâng cấp phần cứng: Bổ sung hoặc thay mới thiết bị vật lý để đáp ứng yêu cầu phần mềm mới. |
| **Heuristic evaluation** | Usability assessment method based on expert review using established guidelines. | Đánh giá Heuristic: Phương pháp chuyên gia rà soát giao diện theo 10 nguyên lý Usability chuẩn. |
| **HIPAA** | Health Insurance Portability and Accountability Act (U.S. healthcare law). | Luật bảo vệ thông tin y tế và hồ sơ bệnh án cá nhân của Hoa Kỳ. |
| **Human Resource Management (HRM)** | A system for managing employee data, such as payroll and recruitment. | Quản trị nguồn nhân lực: Hệ thống quản lý hồ sơ nhân viên, tính lương (payroll) và tuyển dụng. |
| **Human risks** | Risks arising from user resistance, skill gaps, or lack of training. | Rủi ro con người: Nguy cơ phát sinh từ tâm lý ngại thay đổi, thiếu kỹ năng hoặc đào tạo kém. |
| **Hybrid solutions** | Architecture combining on-premises infrastructure with cloud services. | Giải pháp lai (Hybrid): Kiến trúc kết hợp linh hoạt giữa máy chủ nội bộ On-premise và Đám mây. |
| **Implementation costs** | Total expenses incurred during setup, including hardware, software, and labor. | Chi phí triển khai: Tổng chi phí mua sắm phần cứng, bản quyền, tư vấn và nhân công cài đặt. |
| **Implementation delays** | Disruptions in the planned schedule for deploying a system. | Chậm tiến độ triển khai: Tình trạng dự án bị trễ hạn so với kế hoạch ban đầu. |
| **Industry reports** | Published assessments comparing IT products or vendors (e.g., Gartner). | Báo cáo ngành: Đánh giá độc lập so sánh các sản phẩm/nhà cung cấp CNTT trên thị trường. |
| **Infrastructure as a Service (IaaS)** | Cloud model providing virtualized computing resources online (e.g., AWS EC2). | Hạ tầng như một dịch vụ: Dịch vụ đám mây cung cấp máy chủ ảo, lưu trữ và mạng. |
| **Integration** | Connecting different systems to work as a unified solution. | Tích hợp hệ thống: Kết nối các phần mềm rời rạc để hoạt động đồng bộ như một khối thống nhất. |
| **Intuitiveness** | Measure of how easily users understand and navigate a system. | Tính trực quan: Độ dễ hiểu và dễ điều hướng của giao diện ngay lần đầu sử dụng. |
| **Latency** | Time delay between user action and system response. | Độ trễ: Khoảng thời gian trễ từ khi người dùng gửi yêu cầu đến khi nhận phản hồi. |
| **Licensing fees** | Costs for the legal use of proprietary software or services. | Phí bản quyền: Chi phí trả định kỳ hoặc một lần để được phép sử dụng phần mềm hợp pháp. |
| **Long-term savings** | Financial benefits realized over time due to efficiency or lower maintenance. | Tiết kiệm dài hạn: Lợi ích tài chính tích lũy qua thời gian nhờ tối ưu vận hành. |
| **Maintenance costs** | Recurring expenses required to support and update a system. | Chi phí bảo trì: Chi phí định kỳ để duy trì, sửa lỗi và nâng cấp hệ thống hoạt động ổn định. |
| **Market share** | Percentage of total sales in a market captured by a vendor or product. | Thị phần: Tỷ lệ phần trăm doanh số thị trường mà sản phẩm/nhà cung cấp nắm giữ. |
| **Net benefit** | Difference between total expected benefits and total costs. | Lợi ích ròng: Giá trị chênh lệch giữa tổng lợi ích thu về trừ đi tổng chi phí bỏ ra. |
| **Net Present Value (NPV)** | Calculation determining the present value of future cash flows. | Giá trị hiện tại thuần: Giá trị quy về hiện tại của dòng tiền trong tương lai trừ chi phí đầu tư. |
| **On-premises storage** | Data storage using local servers rather than cloud infrastructure. | Lưu trữ cục bộ (On-premises): Lưu dữ liệu trên hệ thống máy chủ vật lý đặt tại doanh nghiệp. |
| **Operational feasibility** | Review of whether a system functions effectively in the existing environment. | Tính khả thi vận hành: Đánh giá khả năng hoạt động trơn tru của hệ thống trong môi trường thực tế. |
| **Operational risks** | Potential disruptions to business processes caused by system issues. | Rủi ro vận hành: Nguy cơ gián đoạn hoạt động kinh doanh do sự cố hệ thống gây ra. |
| **Organizational culture** | Collective attitudes and practices influencing system adoption and use. | Văn hóa tổ chức: Thói quen, thái độ của tập thể ảnh hưởng đến mức độ tiếp nhận công nghệ mới. |
| **Performance metrics** | KPIs used to evaluate system speed, capacity, and effectiveness. | Chỉ số đo lường hiệu năng: Các chỉ số kỹ thuật đo lường tốc độ, dung lượng và độ ổn định. |
| **Pilot testing** | Small-scale test run to validate solution performance before full rollout. | Kiểm thử thử nghiệm (Pilot): Chạy thử nghiệm trên quy mô nhỏ trước khi triển khai toàn diện. |
| **Platform as a Service (PaaS)** | Cloud offering for developers to build, deploy, and manage apps (e.g., Heroku). | Nền tảng như một dịch vụ: Cung cấp môi trường sẵn sàng để dev phát triển và deploy ứng dụng. |
| **Process mapping** | Visually representing workflows using tools such as DFDs or BPMN. | Sơ đồ hóa quy trình: Trực quan hóa các bước thực hiện công việc bằng DFD, BPMN hoặc UML. |
| **Regulatory compliance** | Adherence to mandatory laws and standards (e.g., HIPAA, GDPR). | Tuân thủ quy định: Bắt buộc đáp ứng đúng các quy định pháp luật hiện hành. |
| **Resource utilization** | Measure of how efficiently CPU, memory, storage, and network are used. | Mức độ sử dụng tài nguyên: Đánh giá hiệu suất tiêu hao phần cứng (CPU, RAM, Disk, Mạng). |
| **Return on Investment (ROI)** | Financial metric comparing benefits gained against costs incurred. | Tỷ suất hoàn vốn đầu tư: Chỉ số tài chính đo lường hiệu quả sinh lời của khoản đầu tư IT. |
| **Risk management** | Strategies to identify, assess, and mitigate project risks. | Quản trị rủi ro: Quy trình nhận diện, đánh giá và lập kế hoạch giảm thiểu rủi ro dự án. |
| **Scalability** | System's capacity to handle increased workload or expansion without degradation. | Khả năng mở rộng: Năng lực chịu tải tăng cao mà không làm suy giảm hiệu năng hệ thống. |
| **Security** | Measures implemented to protect systems and data from unauthorized access. | An ninh bảo mật: Các biện pháp kỹ thuật bảo vệ dữ liệu và hệ thống khỏi truy cập trái phép. |
| **Security breaches** | Incidents involving unauthorized access, loss, or exposure of sensitive data. | Vi phạm an ninh mạng: Sự cố rò rỉ, mất mát hoặc bị tấn công đánh cắp dữ liệu nhạy cảm. |
| **Software as a Service (SaaS)** | Cloud delivery model where apps are hosted and accessed online (e.g., Salesforce). | Phần mềm như một dịch vụ: Mô hình cho thuê phần mềm chạy trên Cloud truy cập qua Web/App. |
| **Stakeholder engagement** | Involving users and decision-makers to align expectations and build buy-in. | Gắn kết các bên liên quan: Lôi kéo sự tham gia của người dùng và quản lý để thống nhất mục tiêu. |
| **Stakeholder feedback** | Information collected from users to guide improvements. | Phản hồi của các bên liên quan: Ý kiến đóng góp từ người dùng thực tế để cải tiến hệ thống. |
| **Supply Chain Management (SCM)** | A system that manages logistics, procurement, and inventory. | Quản lý chuỗi cung ứng: Hệ thống điều phối luồng hàng hóa từ nhà cung ứng đến khách hàng. |
| **System architecture** | The structural design defining system components, modules, and interactions. | Kiến trúc hệ thống: Bản thiết kế cấu trúc định hình các phân hệ và cách thức tương tác. |
| **System documentation** | Comprehensive description of a system's design, components, and processes. | Tài liệu hóa hệ thống: Bản ghi chi tiết về cấu tạo, chức năng và hướng dẫn vận hành hệ thống. |
| **Task analysis** | Assessing user tasks to identify inefficiencies, steps, and bottlenecks. | Phân tích tác vụ: Bóc tách từng bước thao tác của người dùng để tìm điểm nghẽn và thao tác thừa. |
| **Technical risks** | Risks related to system functionality, reliability, or integration failures. | Rủi ro kỹ thuật: Nguy cơ phát sinh từ lỗi phần mềm, sập server hoặc không tích hợp được API. |
| **Throughput** | Rate at which a system processes data or transactions per unit time. | Thông lượng (Throughput): Tốc độ và khối lượng giao dịch hệ thống xử lý trong một đơn vị thời gian. |
| **Total Cost of Ownership (TCO)** | Calculation of all costs associated with acquiring, operating, and maintaining a solution. | Tổng chi phí sở hữu: Toàn bộ chi phí vòng đời: Mua sắm, Triển khai, Đào tạo, Vận hành và Bảo trì. |
| **Usability testing** | Evaluating how easily users can complete tasks within a system. | Kiểm thử tính khả dụng: Đánh giá mức độ dễ dùng qua việc quan sát người dùng thao tác thực tế. |
| **User Experience (UX)** | Overall impression, satisfaction, and ease of use when interacting with a system. | Trải nghiệm người dùng: Cảm nhận tổng thể về sự mượt mà, tiện lợi và hài lòng khi dùng sản phẩm. |
| **User Interface (UI)** | Visual and interactive elements that allow users to operate a system. | Giao diện người dùng: Các thành phần đồ họa trực quan (nút bấm, màu sắc, form) để tương tác. |
