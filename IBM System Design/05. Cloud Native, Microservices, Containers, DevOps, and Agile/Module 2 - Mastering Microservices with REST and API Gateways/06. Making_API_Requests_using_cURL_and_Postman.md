# Gửi Yêu Cầu API bằng cURL và Postman (Making API Requests using cURL and Postman)

Tài liệu này tóm tắt nội dung bài học **Making API Requests using cURL and Postman** trong **Module 2: Mastering Microservices with REST and API Gateways** thuộc khóa học **Cloud Native, Microservices, Containers, DevOps, and Agile** do IBM cung cấp.

---

## 1. Công cụ Dòng lệnh cURL (Client URL)

### Khái niệm & Bối cảnh
*   **cURL** (viết tắt của *Client URL*, phát triển từ năm 1998) là công cụ dòng lệnh (*command-line tool*) kinh điển dùng để truyền nhận dữ liệu qua mạng thông qua các URL.
*   **Giao thức hỗ trợ**: Đa dạng giao thức mạng như **HTTP, HTTPS, FTP, IMAP**, v.v.
*   **Phương thức sử dụng**: Chạy trực tiếp từ Terminal/CLI hoặc tích hợp vào các kịch bản tự động hóa (*automation scripts*).

### Các Ca sử dụng Phổ biến (Common Use Cases)
1.  **Kiểm thử Endpoint (*Endpoint Testing*)**: Gọi thử các REST API nhanh chóng từ giao diện console.
2.  **Gỡ lỗi (*Debugging*) & Ghi log**: Kiểm tra mã phản hồi HTTP (*Status Code*), headers và body trả về.
3.  **Tải tệp tin**: Tải tài nguyên từ máy chủ từ xa về máy cục bộ.

### Cú pháp và Các Cờ (Flags/Options) Cơ bản
cURL chấp nhận rất nhiều tùy chọn (options) với dấu gạch ngang đơn (`-`) hoặc đôi (`--`):

```bash
# Ví dụ gọi GET request đến Products Microservice với Header yêu cầu JSON
curl -X GET "https://api.example.com/products" -H "Accept: application/json"
```

*   `-X <METHOD>`: Chỉ định rõ phương thức HTTP cần dùng (`GET`, `POST`, `PUT`, `DELETE`,...).
*   `-H "<Header>"`: Thiết lập thông tin tiêu đề HTTP (*HTTP Header*), ví dụ khai báo kiểu dữ liệu trao đổi `application/json`.
*   `-d "<Body Data>"`: Gửi kèm dữ liệu body (thường dùng trong `POST`/`PUT`).

## 2. Nền tảng Phát triển & Kiểm thử API Postman

### Khái niệm & Vai trò
*   **Postman** là một nền tảng toàn diện (*API Platform*) với giao diện đồ họa trực quan (GUI) mạnh mẽ, giúp nhà phát triển dễ dàng **xây dựng, kiểm thử, tài liệu hóa và chia sẻ API**.
*   Đơn giản hóa toàn bộ **vòng đời API (*API Lifecycle*)**:
    *   Hỗ trợ tổ chức, liên kết và điều phối nhiều request phức tạp (*orchestration*).
    *   Thực hiện chạy kiểm thử lặp lại theo lô (*Collection Runner / Iterations*).
    *   Hỗ trợ làm việc nhóm và cộng tác hiệu quả (*Team Workspace*).
    *   Tự động sinh mã nguồn gọi API (*Code Generation*) sang nhiều ngôn ngữ lập trình như **JavaScript, Python, C#, Java, PHP**, v.v.

### Ví dụ Thực tế: WhatsApp Business Cloud API
*   Nền tảng WhatsApp Cloud API sử dụng Postman Collection để chuẩn hóa trải nghiệm cho nhà phát triển.
*   Nhờ các dữ liệu và request được cấu hình sẵn (*pre-filled data & automation*), thời gian tích hợp và kiểm thử của developer được rút ngắn từ nhiều ngày xuống **chỉ còn vài phút**.

### Quy trình Kiểm thử API cơ bản trên Postman
1.  **Khởi tạo**: Mở tab mới trên giao diện Postman.
2.  **Chọn Phương thức & URL**: Chọn HTTP Method (`GET`, `POST`,...) và dán đường dẫn API Endpoint.
3.  **Cấu hình Headers / Body** (nếu có): Thêm tham số Query, Authorization token hoặc Payload JSON.
4.  **Thực thi**: Nhấn nút **Send** và phân tích kết quả trả về (Status code, Response Time, JSON Body).
5.  **Lưu trữ**: Lưu request vào **Collection / Workspace** để tái sử dụng trong tương lai.

## 3. So sánh cURL và Postman

| Tiêu chí | cURL | Postman |
| :--- | :--- | :--- |
| **Giao diện** | Giao diện dòng lệnh (CLI / Terminal) | Giao diện đồ họa trực quan (GUI) + Web App |
| **Môi trường phù hợp** | Server không có GUI, CI/CD pipelines, Bash scripts | Phát triển tính năng, kiểm thử luồng nghiệp vụ, làm việc nhóm |
| **Tự động hóa & Scripting** | Nhẹ, dễ nhúng vào Shell script / Makefile | Hỗ trợ Tests script (JavaScript), Pre-request scripts |
| **Tài liệu hóa & Chia sẻ** | Chia sẻ dưới dạng câu lệnh thô | Tạo API Documentation tự động, chia sẻ qua Workspace/Collections |
| **Sinh mã nguồn (Code Gen)** | Cần viết thủ công | Tự động xuất mã nguồn đa ngôn ngữ |

---

## 4. Tóm tắt Điểm then chốt (Key Takeaways)

1.  **cURL**: Công cụ CLI kinh điển, nhẹ và mạnh mẽ để truyền nhận dữ liệu qua URL, lý tưởng cho scripting và CI/CD.
2.  **Postman**: Nền tảng hoàn chỉnh cho toàn bộ vòng đời API, hỗ trợ kiểm thử trực quan, tự động hóa và cộng tác nhóm.
3.  Cả hai công cụ đều hỗ trợ đầy đủ các phương thức HTTP chuẩn (`GET`, `POST`, `PUT`, `PATCH`, `DELETE`) để làm việc với RESTful Microservices.
