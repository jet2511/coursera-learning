# Course Introduction – Tóm tắt

**Khóa học:** Software Testing, Deployment, and Maintenance Strategies  
**Nhà cung cấp:** IBM / Coursera  
**Ngày lưu:** 2026-10-14

---

## 🎯 Tổng quan khóa học

> Phát triển phần mềm không chỉ là viết code. **Hơn một nửa tổng công sức của dự án** nằm ở những gì diễn ra sau khi code xong.

Khóa học trang bị kỹ năng cho các chuyên gia IT trong việc **tối ưu hóa hệ thống phần mềm** qua 3 giai đoạn: Testing – Deployment – Maintenance.

---

## 📚 Nội dung sẽ học

| Chủ đề | Chi tiết |
|--------|----------|
| **Testing** | Unit, Integration, System, User Acceptance Testing (UAT) |
| **Test Cases** | Viết test case hiệu quả, sử dụng Traceability Matrix |
| **TDD / BDD** | Test-Driven Development, Behavior-Driven Development |
| **Gherkin Syntax** | Tạo collaborative test scenarios |
| **Deployment** | Lập kế hoạch release, workflow triển khai phần mềm |
| **Data Migration** | Validate và migrate dữ liệu chính xác |
| **Monitoring** | Giám sát hệ thống, chiến lược bảo trì |
| **Non-Functional Req.** | Performance, Scalability, Reliability, Disaster Recovery |

---

## 🗂️ Cấu trúc khóa học

```
Module 1 – Testing Strategies and Practices
  ↳ Test planning, coverage, TDD, BDD, Gherkin Syntax

Module 2 – Software Deployment, Release, and Maintenance Strategies
  ↳ Pre-launch planning, data migration, post-launch monitoring

Module 3 – Non-Functional Requirements
  ↳ Performance, scalability, capacity planning, backup & disaster recovery

Module 4 – Final Project, Final Exam, and Course Wrap-Up
  ↳ Xây dựng Testing & Release Planning Kit hoàn chỉnh
```
