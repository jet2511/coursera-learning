## 🏗️ 4 Cấp độ kiểm thử (Software Testing Levels)

| Cấp độ Test | Đối tượng / Phạm vi | Mục đích chính | Đặc điểm kỹ thuật & Phương pháp áp dụng |
|-------------|---------------------|----------------|-----------------------------------------|
| **1. Unit Testing** | Đơn vị / module độc lập của một lập trình viên | Xác nhận từng module riêng lẻ hoạt động đúng thiết kế (*"Is my module working?"*) | - Đòi hỏi **hiểu sâu code nội bộ** (White-box testing).<br>- Test cả **Happy path** (data chuẩn) lẫn **Sad path** (data lỗi, ngoại lệ `if/else`, exception handlers).<br>- Chạy trong CI server khi push code.<br>- Là nơi áp dụng **TDD (Test-Driven Development)**. |
| **2. Integration Testing** | Kết hợp nhiều units / modules lại với nhau | Phát hiện lỗi trong sự tương tác và giao tiếp giữa các module (*"Do they talk to each other correctly?"*) | - Người test thường **không cần biết chi tiết ruột** từng module (Black/Gray-box).<br>- Kiểm tra lời gọi API giữa các service/module.<br>- Là nơi áp dụng **BDD (Behavior-Driven Development)** để test hành vi cụ thể khi phối hợp. |
| **3. System Testing** | Toàn bộ hệ thống hoàn chỉnh sau khi tích hợp | Đánh giá sự tuân thủ toàn diện theo tài liệu đặc tả yêu cầu hệ thống | - Chạy trong môi trường **Staging / Pre-production** (giống hệt Production).<br>- Kiểm tra luồng end-to-end, performance, bảo mật, compliance. |
| **4. User Acceptance Testing (UAT)** | Hệ thống hoàn chỉnh dưới góc nhìn người dùng cuối / nghiệp vụ | Đánh giá hệ thống có đáp ứng yêu cầu kinh doanh và sẵn sàng để nghiệm thu / bàn giao hay không | - Thực hiện bởi **End Users / Khách hàng / Stakeholders** trước khi ký nghiệm thu ("I accept the system").<br>- Thường chạy trên môi trường chuyên biệt hoặc tương tự Staging. |

## 🔄 Release Cycle & Môi trường triển khai (Environments)

Quy trình dịch chuyển artifact từ máy lập trình viên ra tới người dùng thực tế:

```
[Development / SCM (Git)] 
       │ 
       ▼ (Unit Test & Code Commit)
[Build Environment / CI] ───► Lưu artifacts (Jar, Wheels, Docker images) vào Package Repository
       │
       ▼ Deploy artifacts
[Test Environment] ──────────► Integration Testing, Functional Testing
       │
       ▼ Deploy
[Staging / Pre-Prod] ────────► System Testing, Performance Testing, Compliance, UAT
       │
       ▼ Go-Live
[Production] ────────────────► Hệ thống chạy thực tế phục vụ người dùng cuối
```

### Điểm mấu chốt:
1. **Môi trường càng về sau càng giống Production**: Giúp thực hiện được các bài test phức tạp (Performance, Compliance, Load test, End-to-end UAT) mà môi trường Dev nhỏ lẻ không thể mô phỏng được.
2. **Unit Testing** gắn liền với pha **Development & Build**.
3. **Integration, System, Acceptance Testing** diễn ra ở các pha **Test, Staging và Pre-Production**.
