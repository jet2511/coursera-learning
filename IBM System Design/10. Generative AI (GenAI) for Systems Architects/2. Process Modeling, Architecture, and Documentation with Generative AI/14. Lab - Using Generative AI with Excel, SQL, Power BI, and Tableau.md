# Lab: Using Generative AI with Excel, SQL, Power BI, and Tableau

## 1. Tóm tắt nội dung thực hành (Lab Summary)

Lab cung cấp kỹ năng ứng dụng Generative AI vào chuỗi phân tích dữ liệu kinh doanh gồm 3 bước thực hành cốt lõi:
1. **Executive Summary:** Dịch mô tả kỹ thuật dữ liệu thành bản tóm tắt súc tích, phi kỹ thuật (không dùng thuật ngữ rối rắm), nêu bật giá trị kinh doanh và hỗ trợ ra quyết định.
2. **Text-to-SQL Conversion:** Chuyển đổi câu hỏi nghiệp vụ bằng ngôn ngữ tự nhiên thành truy vấn SQL tối ưu (kèm mệnh đề GROUP BY, ORDER BY, Aggregation) dựa trên cấu trúc bảng định trước.
3. **Dashboard Specification:** Thiết kế tài liệu đặc tả Dashboard (cho Power BI, Tableau hoặc Excel), bao gồm lựa chọn loại biểu đồ phù hợp theo mục đích (KPI cards, bar chart, line chart), bố cục phân cấp và bộ lọc tương tác.

### Bài tập 2: Sinh truy vấn SQL từ câu hỏi nghiệp vụ (Text-to-SQL)

- **Prompt mẫu:**
  ```text
  "Write an SQL query to answer this question: [Question]. Use this table structure: [Table schema]. Include appropriate GROUP BY, ORDER BY, and aggregate functions. Add comments explaining each part."
  ```

#### Câu hỏi 1: Tổng doanh thu và số lượng đơn hàng theo từng tháng là bao nhiêu?
```sql
-- Tính tổng doanh thu và tổng số đơn hàng theo tháng để theo dõi xu hướng
SELECT 
    DATE_TRUNC('month', order_date) AS sales_month,
    COUNT(order_id) AS total_orders,
    SUM(order_amount) AS total_revenue
FROM 
    orders
GROUP BY 
    DATE_TRUNC('month', order_date)
ORDER BY 
    sales_month ASC;
```

#### Câu hỏi 2: Top 3 danh mục sản phẩm mang lại doanh thu cao nhất?
```sql
-- Lấy top 3 danh mục sản phẩm có tổng doanh thu lớn nhất
SELECT 
    product_category,
    SUM(order_amount) AS category_revenue
FROM 
    orders
GROUP BY 
    product_category
ORDER BY 
    category_revenue DESC
LIMIT 3;
```

#### Câu hỏi 3: Giá trị đơn hàng trung bình (AOV) của từng phân khúc khách hàng?
```sql
-- Tính Average Order Value (AOV) cho từng phân khúc khách hàng
SELECT 
    customer_segment,
    COUNT(order_id) AS orders_count,
    ROUND(AVG(order_amount), 2) AS average_order_value
FROM 
    orders
GROUP BY 
    customer_segment
ORDER BY 
    average_order_value DESC;
```

### Bài tập 3: Thiết kế tài liệu đặc tả Dashboard (Dashboard Specification)

- **Công cụ đích:** Power BI / Tableau / Excel
- **Mục tiêu:** Cung cấp cái nhìn toàn diện về hiệu suất doanh thu, phân bổ khách hàng và sản phẩm cho Giám đốc kinh doanh.

#### Quy tắc lựa chọn trực quan (Visualization Guidelines)
- **KPI Cards:** Hiển thị số liệu đơn lẻ trọng tâm (Tổng doanh thu, Tổng đơn hàng, AOV).
- **Line Chart:** Thể hiện xu hướng theo thời gian (Doanh thu theo tháng).
- **Bar / Column Chart:** So sánh các nhóm hạng mục (Doanh thu theo danh mục, khu vực).
- **Heat Map / Donut Chart:** Phân bổ tỷ lệ phân khúc khách hàng (sử dụng có chừng mực).

#### Cấu trúc đặc tả bố cục Dashboard (Dashboard Layout Specification)

| Vị trí (Position) | Thành phần trực quan (Component) | Loại biểu đồ (Chart Type) | Dữ liệu hiển thị (Metrics & Dimensions) | Mục đích nghiệp vụ (Business Purpose) |
| :--- | :--- | :--- | :--- | :--- |
| **Top Header** | **Bộ chỉ số KPI chính** | KPI Cards | - Tổng doanh thu (`SUM`)<br>- Tổng số đơn hàng (`COUNT`)<br>- Giá trị đơn trung bình (`AVG`) | Nắm bắt sức khỏe doanh thu trong 3 giây đầu tiên |
| **Hàng 1 (Chính)** | **Xu hướng doanh thu theo tháng** | Line Chart | - Trục X: Tháng (`order_date`)<br>- Trục Y: Doanh thu (`order_amount`) | Theo dõi đà tăng trưởng và tính chu kỳ mùa vụ |
| **Hàng 2 (Trái)** | **Doanh thu theo danh mục sản phẩm** | Horizontal Bar Chart | - Trục Y: Danh mục (`product_category`)<br>- Trục X: Doanh thu (`SUM`) | Nhận diện sản phẩm chủ lực để ưu tiên nhập hàng |
| **Hàng 2 (Phải)** | **Tỷ trọng doanh thu theo phân khúc** | Donut Chart | - Lát cắt: Phân khúc khách hàng<br>- Giá trị: % Doanh thu | Đánh giá mức độ đóng góp của từng nhóm đối tượng |
| **Thanh bên (Sidebar)** | **Bộ lọc tương tác (Slicers/Filters)** | Dropdown / Date Picker | - Khoảng thời gian (Date Range)<br>- Khu vực (Region)<br>- Phân khúc khách hàng | Cho phép người dùng drill-down chi tiết theo ngữ cảnh |
