---

## 1. Tổng quan lộ trình khóa học (Course Roadmap)

Khóa học cung cấp kiến thức toàn diện từ lý thuyết, kiến trúc đến thực hành xây dựng Data Lake trên hạ tầng AWS qua 6 Modules:

| Module | Tên Module | Trọng tâm kiến thức & Dịch vụ |
| :--- | :--- | :--- |
| **Module 1** | **Introduction to Data Lakes** | • Định nghĩa & Giá trị cốt lõi của Data Lake<br>• So sánh Data Lake vs Data Warehouse<br>• Các thành phần & Kiến trúc nền tảng của Data Lake |
| **Module 2** | **Data Ingestion, Cataloging, and Preparation** | • Dịch vụ lưu trữ & xử lý: **Amazon S3, AWS Glue, Amazon Athena**...<br>• Kỹ thuật thu thập, phân loại danh mục (Cataloging) và chuẩn bị dữ liệu |
| **Module 3** | **Building a data lake with AWS Lake Formation** | • Giới thiệu & Cấu trúc cơ bản của **AWS Lake Formation**<br>• **Self-paced Lab:** Thực hành tạo và cấu hình Lake Formation trên môi trường được cấp sẵn |
| **Module 4** | **Data processing and analytics** | • Xử lý và biến đổi dữ liệu sau khi ingest<br>• Tận dụng hệ sinh thái AWS Glue: **AWS Glue DataBrew**, **AWS Glue Studio** |
| **Module 5** | **AWS Lake Formation additional configurations and capabilities** | • Tính năng nâng cao: Blueprints, Workflows, Fine-grained Access Control, Lake Formation Tags (LF-TBAC)...<br>• Trực quan hóa dữ liệu (BI/Reporting) với **Amazon QuickSight**<br>• **Self-paced Lab:** Thực hành cấu hình nâng cao |
| **Module 6** | **Modern data architecture on AWS** | • Các mô hình kiến trúc hiện đại, luân chuyển và chia sẻ dữ liệu (Data Mesh, Lake House sharing models)<br>• **Self-paced Lab:** Thực hành kiến trúc dữ liệu hiện đại |
