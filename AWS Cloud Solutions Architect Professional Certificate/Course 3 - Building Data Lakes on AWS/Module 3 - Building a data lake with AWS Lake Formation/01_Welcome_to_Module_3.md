# Module 3: Building a data lake with AWS Lake Formation

## Bài học: Welcome to Module 3

### 1. Tổng quan & Mục tiêu chính của Module 3
Module 3 là phần nhập môn về **AWS Lake Formation**, tập trung vào các khái niệm nền tảng để thiết lập và quản trị Data Lake:

- **Features & Benefits**: Giới thiệu các tính năng cốt lõi và lợi ích của AWS Lake Formation trong việc đơn giản hóa, tự động hóa quy trình xây dựng Data Lake.
- **Data Lake Creation**: Cách sử dụng Lake Formation để thiết lập, đăng ký tài nguyên lưu trữ (S3) và khởi tạo Data Lake một cách tập trung.
- **Lake Formation Security Model**: Tìm hiểu cơ chế quản trị bảo mật và phân quyền tập trung (Centralized permissions model) ở cấp độ database, table, column thay vì chỉ quản lý thô bằng S3 Bucket Policies / IAM.
