# Tóm tắt bài học: Giới thiệu Tuần 2 (Week 2 Introduction)

**Khóa học:** Course 2 - Architecting Solutions on AWS  
**Chủ đề:** Giới thiệu bối cảnh, vai trò và mục tiêu thiết kế giải pháp Data Analytics trong Tuần 2  
**Vị trí:** Module 2 - Designing a serverless data analytics solution on AWS

---

## 1. Bối cảnh và Phân vai trong Tuần 2 (Role-playing Setup)
* **Người hướng dẫn:** Giảng viên **Raf** (người đóng vai khách hàng ở Tuần 1) trong tuần này sẽ đóng vai trò là **Solutions Architect (SA)** hỗ trợ khách hàng đạt được các mục tiêu kinh doanh.
* **Hồ sơ Khách hàng (Customer Profile):**
  * **Mô hình kinh doanh:** Công ty phần mềm cung cấp giải pháp menu điện tử cho nhà hàng thông qua mã **QR Code**.
  * **Thế mạnh kỹ thuật:** Đội ngũ phát triển có kỹ năng lập trình (coding expertise) tốt.
  * **Vấn đề / Nhu cầu:** Cần hỗ trợ thiết kế kiến trúc hạ tầng phân tích dữ liệu (**Data Analytics Infrastructure**) để:
    1. **Ingest** (Thu nạp dữ liệu).
    2. **Process** (Xử lý dữ liệu).
    3. **Visualize** (Trực quan hóa dữ liệu).
  * **Mục tiêu kinh doanh:** Bổ sung tính năng phân tích dữ liệu vào sản phẩm chính nhằm tăng lợi thế cạnh tranh trên thị trường.

---

## 2. Các chủ đề trọng tâm trong Tuần 2 (Key Learning Topics)
* **Amazon S3:** Nền tảng lưu trữ dữ liệu (Data Lake / Storage backbone).
* **Data Ingestion, Processing & Visualization:** Quy trình thu nạp, xử lý và trực quan hóa dữ liệu phù hợp với yêu cầu thực tế của khách hàng.
* **Ánh xạ dịch vụ AWS (Mapping AWS Services):** Cách lựa chọn và kết hợp các dịch vụ phân tích dữ liệu Serverless trên AWS dựa theo nhu cầu và ràng buộc nghiệp vụ.
