# Exam Overview - AWS Certified Solutions Architect - Associate (SAA-C03)

## 1. Thông tin tổng quan kỳ thi (Exam Specifications)

| Tiêu chí | Chi tiết |
| :--- | :--- |
| **Mã kỳ thi (Exam Code)** | SAA-C03 |
| **Cấp độ (Level)** | Associate |
| **Hình thức câu hỏi (Format)** | Multiple choice (1 đáp án đúng) & Multiple response (chọn nhiều đáp án đúng) |
| **Số lượng câu hỏi** | 65 câu (bao gồm 50 câu tính điểm + 15 câu thử nghiệm không tính điểm) |
| **Thời gian làm bài** | 130 phút (có thể yêu cầu thêm **+30 phút** ESL extension nếu tiếng Anh không phải tiếng mẹ đẻ) |
| **Hình thức thi (Delivery)** | Thi tại trung tâm khảo thí Pearson VUE hoặc thi Online có giám thị (Online Proctored) |
| **Chi phí thi (Cost)** | 150 USD (hoặc voucher giảm 50% nếu đã có chứng chỉ AWS trước đó) |
| **Điểm đạt (Passing Score)** | 720 / 1000 điểm (thang điểm từ 100 đến 1000) |
| **Ngôn ngữ hỗ trợ** | Tiếng Anh, Tiếng Pháp, Tiếng Đức, Tiếng Ý, Tiếng Nhật, Tiếng Hàn, Tiếng Bồ Đào Nha, Tiếng Trung (Giản thể/Phồn thể), Tiếng Tây Ban Nha |
